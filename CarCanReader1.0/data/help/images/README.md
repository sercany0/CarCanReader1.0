# Yardım Resimleri

Bu klasörde yardım dosyalarında kullanılan resimler bulunur.

## Gerekli Resimler

Aşağıdaki resimler HTML dosyalarında referans edilmiştir:

1. **installation.png** (600x400 önerilen)
   - Kurulum sihirbazı ekran görüntüsü
   - `getting-started.html` içinde kullanılır

2. **connection-wizard.png** (700x500 önerilen)
   - Bağlantı Wizard'ı ekran görüntüsü
   - `connection.html` içinde kullanılır

3. **connection-status.png** (500x300 önerilen)
   - StatusBar'da bağlantı durumu göstergesi
   - `connection.html` içinde kullanılır

4. **dashboard.png** (800x600 önerilen)
   - Dashboard sekmesi ekran görüntüsü
   - `obd-reading.html` içinde kullanılır

5. **live-charts.png** (800x400 önerilen)
   - Canlı grafikler ekran görüntüsü
   - `obd-reading.html` içinde kullanılır

6. **dtc-list.png** (700x500 önerilen)
   - DTC listesi ekran görüntüsü
   - `dtc-reading.html` içinde kullanılır

7. **dtc-detail.png** (600x500 önerilen)
   - DTC detay penceresi ekran görüntüsü
   - `dtc-reading.html` içinde kullanılır

## Resim Formatı

- **Format:** PNG (şeffaf arka plan desteklenir)
- **Renk Modu:** RGB
- **Çözünürlük:** 72-96 DPI yeterli
- **Boyut:** Yukarıda belirtilen boyutlar önerilendir, daha büyük/küçük olabilir

## Resim Ekleme

1. Ekran görüntüsü alın (Windows: Win+Shift+S)
2. Resmi uygun boyutta kaydedin
3. Bu klasöre kopyalayın
4. HTML dosyaları otomatik olarak resimleri gösterecektir

## Not

Resimler eklenene kadar HTML dosyalarında placeholder görünecektir. Bu normaldir ve resimler eklendiğinde otomatik olarak görüntülenecektir.
