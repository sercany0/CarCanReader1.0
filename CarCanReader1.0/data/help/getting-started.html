🚀 CarCanReader'a Başlarken

CarCanReader, araçlarınızın CAN bus sistemine bağlanarak OBD-II verilerini okumanızı, hata kodlarını görüntülemenizi ve araç sistemlerini yönetmenizi sağlayan profesyonel bir teşhis yazılımıdır.

📖 CarCanReader Nedir?

CarCanReader, modern araçların CAN (Controller Area Network) bus sistemine bağlanarak:

  • Canlı veri okuma: RPM, hız, sıcaklık, yakıt seviyesi gibi gerçek zamanlı sensör verileri
  • Hata kodu yönetimi: DTC (Diagnostic Trouble Code) okuma, görüntüleme ve silme
  • Modül kodlama: Araç modüllerini kodlama ve yapılandırma
  • CAN analizi: CAN mesajlarını analiz etme ve öğrenme
  • Veri kaydetme: Okunan verileri CSV formatında kaydetme
💡 İpucu: CarCanReader, hem amatör hem de profesyonel kullanıcılar için tasarlanmıştır. Basit arayüzü sayesinde kolayca kullanılabilir.

🔌 Desteklenen Adaptörler

CarCanReader aşağıdaki CAN adaptörleri ile uyumludur:

Adaptör Protokol Bağlantı Notlar
CANable SLCAN USB Önerilen - Otomatik algılama
ELM327 OBD-II USB/Bluetooth Bluetooth için ek yapılandırma gerekebilir
OBDLink OBD-II USB Yaygın kullanılan adaptör
Diğer SLCAN uyumlu SLCAN USB Firmware güncellemesi gerekebilir
✅ Önerilen: CANable adaptörü kullanmanız önerilir çünkü:
  • Otomatik algılanır
  • SLCAN protokolü ile tam uyumlu
  • Yüksek hızlı veri aktarımı
  • Açık kaynak ve güvenilir

💻 Sistem Gereksinimleri

Donanım Gereksinimleri

  • İşlemci: Intel Core i3 veya eşdeğer (minimum), Core i5 önerilir
  • RAM: 4 GB (minimum), 8 GB önerilir
  • Disk: 100 MB boş alan
  • USB Port: USB 2.0 veya üzeri (adaptör için)
  • CAN Adaptörü: Uyumlu bir CAN adaptörü (CANable önerilir)

Yazılım Gereksinimleri

  • İşletim Sistemi: Windows 7 SP1, Windows 8.1, Windows 10 veya Windows 11
  • .NET Framework: 4.8 veya üzeri (otomatik yüklenir)
  • USB Sürücüler: CAN adaptörünüz için gerekli sürücüler
⚠️ Önemli: Windows 7 kullanıyorsanız, .NET Framework 4.8'i manuel olarak yüklemeniz gerekebilir. İndirme sayfası

⚙️ Kurulum Adımları

Adım 1: Yazılımı İndirin

CarCanReader'ı resmi web sitesinden veya dağıtım paketinden indirin.

Kurulum sihirbazı - Başlangıç ekranı

Adım 2: Kurulumu Başlatın

  1. İndirilen CarCanReader_Setup.exe dosyasına sağ tıklayın
  2. "Yönetici olarak çalıştır" seçeneğini seçin (gerekirse)
  3. Kurulum sihirbazı açılacaktır
  4. "İleri" butonuna tıklayarak devam edin

Adım 3: Kurulum Seçenekleri

  1. Kurulum Konumu: Varsayılan konumu kullanabilir veya özel bir klasör seçebilirsiniz
  2. Başlat Menüsü: Başlat menüsünde kısayol oluşturulacaktır
  3. Masaüstü Kısayolu: İsterseniz masaüstü kısayolu oluşturabilirsiniz
  4. "Kur" butonuna tıklayın

Adım 4: Kurulum Tamamlandı

Kurulum tamamlandığında:

  • ✅ "Kurulum tamamlandı" mesajı görünecektir
  • ✅ "CarCanReader'ı Başlat" seçeneği ile uygulamayı açabilirsiniz
  • ✅ Veya Başlat menüsünden "CarCanReader" seçeneğini kullanabilirsiniz
💡 İlk Açılış: İlk açılışta uygulama otomatik olarak:
  • data/ klasörünü oluşturur
  • Varsayılan konfigürasyon dosyalarını hazırlar
  • Bağlantı Wizard'ını gösterir (eğer bağlantı yoksa)

🔧 Adaptör Sürücüleri

CANable Sürücüleri

CANable adaptörü kullanıyorsanız:

  1. Adaptörü USB'ye takın
  2. Windows otomatik olarak sürücüleri yükleyecektir
  3. Eğer yüklemezse: CANable GitHub sayfasından sürücüleri indirin

ELM327 Sürücüleri

ELM327 adaptörü kullanıyorsanız:

  1. Adaptörünüzün üretici web sitesinden sürücüleri indirin
  2. Adaptörü USB'ye takın
  3. Sürücü kurulum sihirbazını takip edin
⚠️ Dikkat: İlk kurulumdan sonra CAN adaptörünüzü bağlamadan önce sürücülerin yüklü olduğundan emin olun. Aksi halde adaptör tanınmayabilir.

🎯 Sonraki Adımlar

Kurulum tamamlandıktan sonra:

  1. Adaptörü Bağlayın: CAN adaptörünüzü bilgisayara USB ile bağlayın
  2. Uygulamayı Açın: CarCanReader'ı başlatın
  3. Bağlantı Kurun: Bağlantı rehberini takip ederek ilk bağlantıyı kurun
  4. Keşfedin: Dashboard, Teşhis ve diğer sekmeleri keşfedin
